# Contributing to ds-core

The project's contributing guide, dev setup and issue tracker are in the
landing repository:
[Distant-Signal/distant-signal's CONTRIBUTING.md](https://github.com/Distant-Signal/distant-signal/blob/main/CONTRIBUTING.md).
It covers running the full stack, working across repositories (a local Cargo
`[patch]` onto this checkout) and how changes ship. File issues there with
the `area:core` label; this repository has Issues turned off.

What is specific to this repository is in [CLAUDE.md](CLAUDE.md): the
commands CI runs, the migration rules and how a release is made.
